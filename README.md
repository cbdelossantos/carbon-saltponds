# Data analysis: Carbon sequestration rate and stocks in saltponds

# Overview

This repository contains the script used for the data analysis presented in the scientific article titled "White is a new shade of blue carbon: traditional salt production ponds are net carbon sinks" (submitted). The article investigated saltponds as carbon sinks.        

# Contents

* README.md: This file, containing information about the repository.    
* full_script.R: Script for the data analysis and visualisation for the carbon sequestration rates and stocks.
